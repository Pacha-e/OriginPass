# Referencias de otros stacks

Contiene los archivos `references\` de habilidades que describen stacks ajenos a OriginPass (TypeScript, Vue, Nest y Nuxt). Se conservan como referencia histórica; ninguna habilidad activa los carga.

Los enlaces internos de estos archivos apuntan a rutas del método original y no funcionan desde esta carpeta. Para OriginPass, la aplicación vigente está en `reglas\global-rules.md`, sección "Aplicación a OriginPass (Django)".
