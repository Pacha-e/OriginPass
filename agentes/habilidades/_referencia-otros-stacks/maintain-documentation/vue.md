# Vue application

In course views, retain comment separators for the main sections of the `<script>` block. Review them with the actual section contents, and update them when the layout changes. The professor specifically requested separators: “no hay comentarios que separen los elementos principales en la sección de script” ([source](../../../../knowledge/sources/professor-feedback.md), line 19). The course requirement takes precedence over the general advice to avoid redundant comments ([global rules](../../../../rules/global-rules.md), lines 93–98).
